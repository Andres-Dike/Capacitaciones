Pasos para ejecutar el archivo ToDo.py
Requisitos
Paso 1

Tener instalada la versión 3.14.7x de Python.

Paso 2

Tener instalada la extensión de Python en Visual Studio Code.

Paso 3

Abrir el archivo ToDo.py en Visual Studio Code y ejecutarlo utilizando Python.

Validaciones y funcionamiento

El código valida que el campo nombre de una tarea no esté vacío.

Además, las tareas tienen un estado predeterminado que se establece automáticamente al crear el objeto Task. Por defecto, una nueva tarea se crea como pendiente.

El programa permite:

Agregar tareas.
Listar las tareas registradas.
Marcar tareas como completadas.
Validar que el nombre de la tarea no esté vacio
