Método HTTP	Endpoint	         Caso de uso	            Función
POST	    /tareas	             CrearTarea	                Registra una nueva tarea
GET	        /tareas	             ListarTareas               Obtiene todas las tareas registradas
PUT      	/tareas?nombre=...	 ModificarTarea	            Marca una tarea como completada
