Qué aprendí:
Aprendí qué es una API REST, qué son los endpoints y cómo utilizar los métodos HTTP `GET`, `POST` y `PUT`. También aprendí a crear APIs con FastAPI, ejecutarlas con Uvicorn y probarlas mediante Swagger.

Que practique:
Creé endpoints para registrar, listar y marcar tareas como completadas. Practiqué el envío de parámetros, respuestas en formato JSON y validaciones de datos.

Dónde tuve dificultad:
Tuve dificultad al ejecutar la API debido a los imports y a la forma correcta de iniciar Uvicorn. También tuve problemas al realizar las validaciones desde el caso de uso y no directamente desde el repositorio.

Qué necesito reforzar:
Necesito reforzar los métodos HTTP, códigos de estado, validaciones, manejo de errores y el uso de JSON y Pydantic en FastAPI.
